BFF's proxy removes the `Cookie` header from the outgoing request as a security measure (the session cookie must not reach the upstream API), and does so after/outside normal transforms, so a transform setting `Cookie` is overwritten/ignored. YARP also treats Cookie specially. Workarounds: send the value via a different header (e.g. `X-Api-Cookie`) and have the API read it; or use a custom `HttpMessageInvoker`/ `ForwarderRequestConfig`, or a middleware that adds it later; ideally use bearer tokens instead.
